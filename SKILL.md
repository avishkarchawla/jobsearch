# JobDhoondho Skill

When the user wants to search for jobs across multiple portals, scan direct company careers (Google, Microsoft, Amazon, Stripe, Swiggy, TCS), build Google X-Ray recruiter strings, check ATS resume compatibility, or track job applications in Kanban boards.

## Core Capabilities
1. **Multi-Portal Aggregation:** Generates deep search links for LinkedIn, Naukri, Indeed Global, Glassdoor, Wellfound, RemoteOK, and Cutshort.
2. **Direct Career Site Scanner:** Routes directly to official hiring portals for Google, Microsoft, Amazon, Meta, Apple, Swiggy, and TCS.
3. **ATS Engines (Greenhouse / Lever / Workday / Ashby):** Creates structured Google X-Ray strings targeting hosted job boards.
4. **Client-Side ATS Parser:** In-browser PDF & Word resume extraction without external API dependency.
5. **Kanban Application Tracker:** LocalStorage-persisted dashboard with JSON backup import/export.
