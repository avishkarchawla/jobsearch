## ✨ Features Overview

- 📌 **Job Portals Listed First:** High-priority search query builder for **LinkedIn, Naukri, Indeed Global, Glassdoor, Wellfound (AngelList), RemoteOK, WeWorkRemotely, Cutshort, and Foundit**.
- 🏢 **Direct Company Careers Second:** Direct one-click search for **Google Careers, Microsoft Careers, Amazon Jobs, Meta Careers, Apple Careers, Swiggy, Zomato, and TCS iBegin**.
- ⚡ **Enterprise ATS Engine Scanners:** Built-in deep X-Ray indexers for **Greenhouse.io, Lever.co, Workday Jobs, and AshbyHQ**.
- 🗺️ **2-Part Dependent Location Selector:** Select target country (`India, USA, UK, Canada, UAE, Singapore, Germany, Remote`) to dynamically filter target cities (`Bangalore, San Francisco, London, Dubai, Toronto`, etc.).
- 🏷️ **Brand Name Search Support:** Search for any specific company or brand (e.g. `Google, Stripe, OpenAI, Netflix, Apple, Swiggy`) across all platforms with auto-bound parameters.
- 🎓 **Advanced Experience Tiers:** Filter openings for `0-2 Yrs`, `2-5 Yrs`, `5-10 Yrs`, `10-15 Yrs`, `15-20 Yrs`, and `20+ Yrs / CXO`.
- 🛡️ **In-Browser ATS Match Calculator:** Upload PDF / Word resume directly in the browser to extract skills, action verbs, and quantifiable metrics to compute a live **ATS Bypass % Score**.
- 📋 **Integrated Kanban Job Tracker:** Track your applications through `Applied → Under Review → Interviewing → Offer → Rejected` with LocalStorage persistence and JSON backup import/export.

## ⚡ Quick Start (Local Run)

### Method 1: Double Click
Simply double-click `index.html` to open directly in Google Chrome, Microsoft Edge, or Safari.

### Method 2: Local Python Server (Recommended)
```bash
# Clone or navigate to the repository
cd jobdhoondho

# Run lightweight local server
python3 -m http.server 8092

# Open in your browser
http://localhost:8092
```

## 🌐 Deploy to GitHub Pages (Free Instant Hosting)

1. Push this repository to GitHub.
2. In your GitHub repository, go to **Settings** → **Pages**.
3. Under **Build and deployment** → **Source**, select **Deploy from a branch**.
4. Set branch to `main` / `root` and click **Save**.
5. Your website will be live in seconds at: `https://<your-username>.github.io/<repo-name>/`!
